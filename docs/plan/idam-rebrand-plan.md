# 이담건축 사이트 전환 기획 (a365 클론 → 이담건축)

작성일: 2026-10-24 · 상태: 기획 확정 (추가 결정 반영), 구현 전

## 1. 전제와 원칙

- 이담건축은 **집을 짓는 개인사업자**다. 설계·도면 작업은 하지 않는다. 시공 가능 지역은 **경기 북부**다. 이 사실과 어긋나는 문구는 쓰지 않는다. ("건축 사무소", "설계", "디자인 스튜디오" 금지)
- 화면에 보이는 글자는 **전부 한국어**. 영문 고유명사도 한글로 표기한다. (유튜브, 인스타그램)
- **프론트엔드만** 완성한다. 폼 전송, 지도 API, 챗봇, 분석 도구는 넣지 않는다.
- **기존 UI 구조(a365 클론)를 최대한 유지**하고 내용만 바꾼다. 섹션 추가는 문의 페이지의 자주 묻는 질문·상담 절차 두 곳으로 제한한다.
- 기존 이담 사이트(`idamstudio-web/`)의 텍스트를 기본으로 반영한다.
- 상세 페이지(`/works/[slug]`, `/blog/*`)는 이번 범위에서 제외한다.

## 5. 에셋 계획

- 프로젝트 사진 28장 (약 32MB) → 다운로드 후 **긴 변 2000px, WebP 변환**으로 용량을 줄여 `public/sites/idam/works/<id>/`에 저장.
- Cloudinary 사진 8장 → 같은 방식으로 `public/sites/idam/`.
- Pretendard woff2 (400, 500) → `public/sites/idam/fonts/`.
- 정적 지도 이미지 1장 → 제작 (원본 스타일), `public/sites/idam/map.png`.
- a365 에셋·데이터는 삭제하지 않고 `sites/a365`에 그대로 둔다 (참조 보관).
